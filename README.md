# Diccionario de inglés

Aplicación web para buscar palabras en inglés y ver su definición, fonética y un ejemplo de uso.

Proyecto de aprendizaje de React y APIs, realizado con ayuda de una IA (Claude) como guía paso a paso.

## Funcionalidades

- Búsqueda de palabras en inglés
- Definición, tipo de palabra, fonética y ejemplo
- Lista de favoritos guardada en el navegador (localStorage)
- Mensajes de carga y de error

## Tecnologías

- React (con Vite)
- JavaScript, HTML y CSS
- [Free Dictionary API](https://dictionaryapi.dev/)

## Cómo ejecutarlo

1. Instala Node.js
2. Clona el repositorio y entra en la carpeta
3. Ejecuta `npm install`
4. Ejecuta `npm run dev`
5. Abre la dirección que aparece en la terminal (normalmente http://localhost:5173)

## Notas

El botón de audio depende de los archivos de la API, que a veces no están disponibles.
